# Flashy Language Learning App

## Description
Tkinter GUI flashcard application for vocabulary memorization.

## Features
- Interactive GUI with 3-second card flip
- Progress saving to CSV
- Known word removal

## Technologies
- Python 3.x
- tkinter
- pandas

## Installation
1. Clone the repository:
```bash
   git clone https://github.com/MoayadAlshehry/flashcard-app.git
   cd flashcard-app
```
2. Install dependencies:
```bash
   pip install -r requirements.txt
```

## Usage
Run the application:
```bash
python main.py
```
